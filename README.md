# EB3A Control — Bluetooth-панель для BLUETTI EB3A

Вебзастосунок українською для **локального** керування BLUETTI EB3A через Web Bluetooth. На iPhone відкривайте через браузер **Bluefy** (звичайний Safari не підтримує Web Bluetooth). ESP32, обліковий запис та сервер не потрібні.

## Запуск

1. Відкрийте https://xott69.github.io/Stats/ у Bluefy на iPhone.
2. Увімкніть Bluetooth і натисніть **Підключити EB3A через Bluetooth** на головному екрані.
3. Виберіть EB3A у системному списку та надайте доступ.
4. Після цього відкрийте «Керування», «Історія» або «Налаштування».

З'єднання працює лише поблизу станції й доки браузер зберігає доступ до Bluetooth. Режим «Повторити» на вкладці «Налаштування» використовує поточний пристрій або `navigator.bluetooth.getDevices()` (якщо браузер підтримує). Коли iOS не дає автоматичного повторного підключення — скористайтеся ручною кнопкою «Підключити BLUETTI».

## Реалізоване

- Компактна панель заряду, потужності AC/DC, нетто-балансу та часу останнього успішного зчитування.
- Перемикачі AC (Modbus 3007) / DC (3008), 4 режими LED (3034): LOW=1, HIGH=2, SOS=3, OFF=4.
- Розширені налаштування **ECO 3063**, таймер ECO 3064 (1–4 години), режим заряджання 3065 (Standard=0, Silent=1, Turbo=2), **Power Lifting 3066**.
- Перед кожним керуванням потрібна дія користувача, небезпечні налаштування мають додаткове підтвердження. Кожна команда запису перевіряється читанням того ж регістру. Якщо читання налаштування не вдалося або дані невідомі, відповідний елемент заблокований.
- Локальна історія заряду та вихідної потужності з кроком не частіше хвилини (до 7 днів / 2400 записів), перемикання 1 година / 24 години / 7 днів, експорт CSV, очищення.
- Режим блекауту, оцінка автономності та сценарії навантаження (85% умовного коефіцієнта доступної енергії; **не гарантується**, залежить від втрат інвертора й стану акумулятора).
- Журнал діагностики, без сторонньої аналітики і без надсилання даних на сервер.

## Швидкі сценарії

Вкладка «Керування» → три пресети, які запускаються **тільки після натискання і підтвердження**:

- **🌙 Нічний:** режим заряджання Silent (3065=1), ECO (3063=1), LED вимкнено (3034=4).
- **⚡ Швидкий заряд:** Turbo (3065=2), ECO вимкнено (3063=0).
- **🔋 Економія:** Standard (3065=0), ECO (3063=1), LED вимкнено (3034=4).

Перед виконанням застосунок читає поточні параметри й показує зміни. Після кожного запису перевіряє регістр повторним зчитуванням. У разі помилки зупиняється й вказує частково виконані кроки — без автоматичного відкату. Пресети не змінюють AC/DC-виходи чи Power Lifting. **ECO може вимикати виходи при малому навантаженні, тому не запускай ECO-сценарії, якщо це загрожує підключеним пристроям.** Turbo може збільшити шум і нагрів.

## Важливі обмеження

- **Тестова збірка.** На реальній EB3A підтверджено читання телеметрії та зміну LED. Решту нових команд треба перевіряти на конкретній прошивці. Можливості апаратно обмежені прошивкою й BLE-протоколом.
- У Bluefy можливості Web Bluetooth для `getDevices()`, фонового доступу та експорту файлів залежать від версії браузера / iOS. Не обіцяємо автоматичне з'єднання після перезапуску.
- Коли Bluetooth від'єднано або сторінка закрита, нові точки історії **не записуються**. Дані лише у локальному сховищі *цього* браузера і можуть зникнути після очищення даних браузера.
- ECO може вимкнути виходи при малому споживанні. Перед вимкненням AC / DC переконайтеся, що до них не підключене важливе обладнання.
- Увімкнення Turbo / Power Lifting може збільшити шум, температуру або мати обмеження типів навантаження. Не використовуйте як обхід фізичних лімітів станції.
- Віджет WidgetKit, фоновий моніторинг та незалежна робота без Bluefy **не входять** до цього PWA.

## Публікація

Статичний сайт: GitHub Pages → Deploy from a branch → `main` / `(root)`. За потреби можна використовувати Cloudflare Pages. HTTPS обов'язковий для Bluetooth API.

## Протокол

Використовує BLE service `0000ff00-0000-1000-8000-00805f9b34fb`, notify `ff01`, write `ff02`, Modbus RTU кадри з CRC16. Таблиця доступних регістрів: [Patrick762/bluetti-bt-lib](https://github.com/Patrick762/bluetti-bt-lib/blob/main/bluetti_bt_lib/devices/eb3a.py).

**Усі операції відбуваються напряму з локальної вебсторінки до станції через Bluetooth.**
