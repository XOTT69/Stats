# EB3A Control — експериментальна Web Bluetooth панель

Працює БЕЗ ESP32. Потрібен iPhone із Bluefy та станція BLUETTI EB3A поблизу.

## Публікація

Без серверного коду, акаунтів та секретів. Розмістіть усі файли з каталогу на GitHub Pages, Cloudflare Pages або іншому **HTTPS**-хостингу. Для Cloudflare Pages можна завантажити архів або каталог через **Workers & Pages → Create → Pages → Upload assets**. Коренем має бути `index.html`.

На iPhone встановіть Bluefy (https://apps.apple.com/ua/app/bluefy-web-ble-browser/id1492822055), відкрийте HTTPS-адресу **в Bluefy**, увімкніть Bluetooth, натисніть «Підключити BLUETTI», оберіть станцію. Перед підключенням закрийте офіційний застосунок BLUETTI, щоб він не зайняв BLE-з'єднання.

## Реалізовано

- Web Bluetooth GATT: service FF00, notify FF01, write FF02;
- Modbus RTU CRC16 і збірка фрагментованих BLE-відповідей;
- запити статусу з legacy EB3A регістрів 10–58;
- заряд SOC, AC/DC вхід, AC/DC вихід, оцінка автономності;
- запит стану AC/DC у 3007/3008;
- запис перемикачів 3007/3008 (лише після явного підтвердження) та перевірка прочитуванням;
- опитування кожні 7 сек, графік на час відкритого сеансу, журнал помилок;
- без телеметрії на сторонні сервери.

## Обмеження

Код написано за відкритою документацією реверс-інжинірингу протоколу, **на реальному EB3A не тестувався**. Підтримує незашифрований протокол; деякі ревізії/прошивки можуть відрізнятися. Bluetooth-з'єднання потребує браузера з підтримкою Web Bluetooth. iOS Safari звичайно не підтримує його. Пряме BLE-підключення через Bluefy не гарантовано. Підключення при кожному запуску може вимагати дії користувача. Немає фонової роботи та віддаленого доступу. Небезпечно вимикати AC/DC-вихід, якщо від нього живляться критично важливі пристрої.
