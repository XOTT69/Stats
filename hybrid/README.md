# PowerHub для iPhone (BLUETTI + OUKITEL)

Дві зарядні станції в одному застосунку **Capacitor** (без Home Assistant, ESP32 чи обов'язкової платної підписки Apple).

- **BLUETTI EB3A:** CoreBluetooth через `@capacitor-community/bluetooth-le`, попередній робочий інтерфейс і всі команди (LED, AC/DC, ECO, заряджання, сценарії).
- **OUKITEL P2001E Plus:** локальне TCP 6607 через `@devioarts/capacitor-tcpclient`, Quectel TTLV, nonce + SHA256 авторизація, AES-128-CBC, отримання показників і керування AC/USB/DC за підтвердженням.
- Вкладки вибору станції доступні зверху.
- Жоден API-сервер або додатковий постійно увімкнений пристрій не потрібен **для роботи поруч у домашній мережі**.

## Важливо про стан реалізації

**Це експериментальна iOS-збірка.** BLUETTI через Bluefy уже була перевірена на твоєму пристрої. Нативний BLE-адаптер Capacitor і локальна інтеграція OUKITEL **ще не перевірені на реальних станціях або в Xcode**. До фізичного тестування не використовуй керування для критичних навантажень.

OUKITEL вимагає **персональний authKey** (Base64, 16 байтів після декодування). Він одержується через обліковий запис WonderFree/Quectel. У першій версії автоматичний запит цього ключа ще не реалізовано. Поле у застосунку використовується лише на час підключення: ключ не зберігається на пристрої в localStorage та не входить у GitHub. Не надсилай пароль або ключ у чат чи репозиторій.

Підтверджений протокол для P2001E Plus задокументований у [bordeux/ha-oukitel-powerstation](https://github.com/bordeux/ha-oukitel-powerstation) (MIT). Home Assistant **не встановлюється і не використовується** нашим PowerHub.

## Встановлення на Mac

Встанови Xcode та Node.js, потім:

```bash
git clone https://github.com/XOTT69/Stats.git
cd Stats/hybrid
npm install
npm run build
npx cap add ios
npx cap sync ios
npx cap open ios
```

Якщо репозиторій вже клоновано, замість `git clone` виконай `git pull` в корені `Stats`.

### Права iOS (Info.plist)

Після `npx cap add ios` у Xcode відкрий `ios/App/App/Info.plist` та додай:

```xml
<key>NSBluetoothAlwaysUsageDescription</key>
<string>Bluetooth потрібен для BLUETTI EB3A.</string>
<key>NSLocalNetworkUsageDescription</key>
<string>Доступ до домашньої мережі для OUKITEL P2001E Plus.</string>
```

Вибери **App → Signing & Capabilities → Team (Personal Team)**, потім iPhone як ціль запуску й натисни Run. Безкоштовний підпис зазвичай потребує повторного встановлення щотижня. Дозвіл на локальну мережу iOS необхідний для TCP-з'єднання.

## Перша перевірка

1. Запусти застосунок на iPhone, перевір підключення до EB3A та керування її ліхтариком (без навантажень, які не можна переривати).
2. Переконайся, що OUKITEL та iPhone під'єднані до одного Wi-Fi.
3. Визнач локальну IPv4 OUKITEL у списку клієнтів роутера.
4. Отримай `authKey` **своєї** станції через локальний інструмент (тільки обліковий запис WonderFree у **регіоні EU**):

   ```bash
   python3 tools/wonderfree_key.py
   ```

   Він запитує email і пароль (пароль приховано), звертається напряму до Quectel EU та показує `authKey` тільки у терміналі. Не пересилай пароль або ключ у чат, не зберігай його в GitHub. Інші регіони й зміни API виробника потребуватимуть адаптації. Ключ використовується застосунком лише в пам'яті під час сеансу.
5. На вкладці OUKITEL вкажи локальну IP та ключ, натисни Підключити.
6. Спочатку перевір відображення заряду/потужності, потім (за потреби) AC/USB/DC без критичних приладів.

Якщо станція офлайн для хмари, деякі прошивки не надсилають телеметрію навіть коли LAN-авторизація й команди проходять — це поведінка станції, зазначена дослідниками протоколу.

**На iPhone застосунок не забезпечує безперервної фонової роботи чи гарантії автономної роботи через закритий екран.** Safari/PWA не мають доступу до TCP сокетів, тому OUKITEL-панель працює саме у встановленому iOS-застосунку.
